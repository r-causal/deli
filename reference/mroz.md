# Mroz labor force participation data

Data from Mroz (1987) on married women's labor force participation, used
to demonstrate OLS, 2SLS, and instrumental variable estimation.

## Usage

``` r
mroz
```

## Format

A data frame with 753 rows.

## References

Mroz TA. (1987). The sensitivity of an empirical model of married
women's hours of work to economic and statistical assumptions.
*Econometrica*, 55(4), 765-799.
