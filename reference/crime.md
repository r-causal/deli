# US state crime data

Data on violent crime rates by US state from the 2005 Statistical
Abstract of the United States, used to demonstrate robust regression.

## Usage

``` r
crime
```

## Format

A data frame with 51 rows (50 states + DC).

## References

Agresti A & Finlay B. (2009). *Statistical Methods for the Social
Sciences*, 4th Edition. Pearson.
