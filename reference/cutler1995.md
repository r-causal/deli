# Cutler (1995) pharmacodynamic data

Pharmacodynamic data from Cutler et al. (1995) on acetylcholinesterase
inhibition, used to demonstrate E-max dose-response models.

## Usage

``` r
cutler1995
```

## Format

A data frame.

## References

Cutler NR et al. (1995). Dose-dependent CSF acetylcholinesterase
inhibition by SDZ ENA 713 in Alzheimer's disease. *Acta Neurologica
Scandinavica*, 91(5), 347-351.
