# NSDUH substance use survey data

Data from the National Survey on Drug Use and Health, used to
demonstrate causal mediation analysis.

## Usage

``` r
nsduh
```

## Format

A data frame with approximately 40,000 rows.

## References

Coffman DL, Zhong W. (2021). Assessing mediation using marginal
structural models in the presence of confounding and moderation.
*Psychological Methods*, 17(4), 532.
