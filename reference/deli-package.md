# deli: M-Estimation and Empirical Sandwich Variance Estimation

Provides a general API for M-estimation via solving estimating equations
with empirical sandwich variance estimation. Includes pre-built
estimating equations for basic statistics, regression, causal inference,
survival analysis, measurement error, and pharmacokinetics. An R port of
the Python 'Delicatessen' library.
