# Robust regression example data

Illustrative example of robust linear regression from Zivich et al.
(2022).

## Usage

``` r
robust_regress
```

## Format

A data frame with 15 rows and 3 columns:

- height:

  Height measurement

- weight:

  Weight measurement (with outlier induced at observation 9)

- weight_no_outlier:

  Weight measurement (without outlier)

## References

Zivich PN, Klose M, Cole SR, Edwards JK, & Shook-Sa BE. (2022).
Delicatessen: M-estimation in Python. *arXiv:2203.11300*.
